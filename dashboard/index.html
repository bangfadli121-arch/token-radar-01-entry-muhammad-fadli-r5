Worked example — recompute it yourself

Method, in full: OLS on log10(market cap) against log10(TVL), clamped 7-day growth and a category adjustment (only categories with ≥5 comps get their own; the rest use the global intercept), fitted on the snapshot's token-bearing comps; the age term is a second-stage fit of the residuals on centred log10(age in years + 1) over the comps that carry a listed date. No protocol name is ever special-cased. The same valuation function prices the board and this page's detail drawer.

Implied value is this entry's own claim from the sealed snapshot, never a prediction that a token will be issued or what it will trade at. Built for the make.fun token-radar-01 bounty; source: main.ts + lib/model.ts, fitted at run time.
